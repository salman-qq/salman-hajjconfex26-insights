# محاكي القرارات التقنية | رؤى #hajjconfex2026

موقع تفاعلي من صفحة واحدة يضع الزائر مكان صاحب القرار في منشأة تخدم الحجاج، ويريه سلسلة الأثر التي تترتب على قراره التقني الأول: **ذكاء اصطناعي سريع أم حوكمة بيانات أولاً؟**

إعداد: **سلمان الحربي**، مستشار تقني في حوكمة البيانات وذكاء القرارات.

> مبادرة شخصية مستوحاة من مؤتمر ومعرض خدمات الحج والعمرة 2026، وغير تابعة للجهة المنظمة.

## التقنية

- ملفات ثابتة فقط: **HTML وCSS وVanilla JavaScript** (وحدات ES Modules).
- يعمل 100% داخل المتصفح على **GitHub Pages**: لا Backend ولا قواعد بيانات ولا خوادم.
- لا أطر عمل، ولا خطوة بناء، ولا `package.json`، ولا اعتماديات npm.
- خط **Cairo** مستضاف داخل المستودع (رخصة SIL OFL 1.1).

## المعاينة المحلية

الموقع يستخدم وحدات ES Modules، **ولا يعمل بفتح `index.html` مباشرة من `file://`** لأن المتصفح يمنع تحميل الوحدات منه. شغّل أي خادم ملفات ثابتة من جذر المستودع:

```powershell
# الخيار 1: عبر Node (أداة مؤقتة، لا تُضاف للمشروع)
npx --yes serve .

# الخيار 2: عبر Python
python -m http.server 8000
```

ثم افتح الرابط الذي يظهر (مثل http://localhost:3000 أو http://localhost:8000).

## الاختبارات

Node يُستخدم **للاختبار المحلي فقط**، ولا يُشحن شيء منه مع الموقع. يكفي Node 22 أو أحدث، دون تثبيت أي حزمة:

```powershell
node --test
```

> في PowerShell على Windows، إذا ظهر خطأ «running scripts is disabled» مع `npx`، استخدم `npx.cmd` بدلاً منه.
