# محاكي القرارات التقنية | رؤى #hajjconfex2026

موقع تفاعلي من صفحة واحدة يضع الزائر مكان صاحب القرار في منشأة تخدم الحجاج، ويريه سلسلة الأثر التي تترتب على قراره التقني الأول: **ذكاء اصطناعي سريع أم حوكمة بيانات أولاً؟**

إعداد: **سلمان الحربي**، مستشار تقني في حوكمة البيانات وذكاء القرارات.

**الموقع المنشور (GitHub Pages):** https://salman-qq.github.io/salman-hajjconfex26-insights/

> مبادرة شخصية مستوحاة من مؤتمر ومعرض خدمات الحج والعمرة 2026، وغير تابعة للجهة المنظمة.

## التقنية

- ملفات ثابتة فقط: **HTML وCSS وVanilla JavaScript** (وحدات ES Modules).
- يعمل 100% داخل المتصفح على **GitHub Pages**: لا Backend ولا قواعد بيانات ولا خوادم.
- لا أطر عمل، ولا خطوة بناء، ولا `package.json`، ولا اعتماديات npm.
- خط **Cairo** مستضاف داخل المستودع (رخصة SIL OFL 1.1).

## المعاينة المحلية

الموقع يستخدم وحدات ES Modules، **ولا يعمل بفتح `index.html` مباشرة من `file://`** لأن المتصفح يمنع تحميل الوحدات منه. شغّل أي خادم ملفات ثابتة من جذر المستودع:

```powershell
# الخيار 1: عبر Node (أداة مؤقتة، لا تُضاف للمشروع)
npx --yes serve .

# الخيار 2: عبر Python
python -m http.server 8000
```

ثم افتح الرابط الذي يظهر (مثل http://localhost:3000 أو http://localhost:8000).

## الاختبارات

Node يُستخدم **للاختبار المحلي فقط**، ولا يُشحن شيء منه مع الموقع. يكفي Node 22 أو أحدث، دون تثبيت أي حزمة:

```powershell
node --test
```

> في PowerShell على Windows، إذا ظهر خطأ «running scripts is disabled» مع `npx`، استخدم `npx.cmd` بدلاً منه.

## استبدال أو إضافة صور اللقطات الاستشارية

تُدار جميع اللقطات الاستشارية من موضع واحد هو `CONTENT_CATALOG.insights.items` في ملف `js/content-catalog.js` دون الحاجة لتعديل `index.html` أو ملفات الأنماط أو المنطق البرمجي:

1. **مكان حفظ الصور**: ضع ملفات الصور الفعلية داخل المجلد `assets/insights/` (بمسار محلي نسبي مثل `assets/insights/insight-01.webp`، وتجنب الروابط الخارجية).
2. **الأبعاد والصيغة الموصى بها**: صيغة **`WebP`** مضغوطة، بأبعاد **`800×500` بكسل** (نسبة عرض إلى ارتفاع **`16:10`**) لبطاقات الشبكة لمنع قفز التخطيط (`CLS`) وللحفاظ على التحميل الكسول (`loading="lazy"`). وعند اختلاف أبعاد الصورة الطولية الكاملة عن `16:10`، أضف حقول `lightboxSrc` و`lightboxWidth` و`lightboxHeight` لعرض النسخة الكاملة داخل نافذة التكبير.
3. **تحديث أو إضافة بطاقة**:
   - لاستبدال صورة بديلة حالية: حدّث قيمة `imageSrc` إلى مسار الصورة الجديدة، واضبط `isPlaceholder: false`، وحدّث `alt` و`commentary` إذا لزم الأمر.
   - لإضافة لقطة سابعة (أو أكثر): أضف عنصراً جديداً إلى مصفوفة `items` في `js/content-catalog.js` بالحقول `id`, `tag`, `title`, `imageSrc`, `alt`, `commentary` (مع `isPlaceholder: false` عند وجود صورة فعلية).
4. **تنبيه الخصوصية والتركيز البصري**: تجنّب في الصور الملتقطة ظهور **وجوه الزوار أو بطاقات أسماء العارضين والجهات**، واجعل التركيز موجهاً على الأدوات التقنية والشاشات والنماذج التشغيلية فقط.
